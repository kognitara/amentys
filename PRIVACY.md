# Privacy and Telemetry

## Project policy

Amentys does not intentionally collect, transmit, or sell personal data as part of the source
code in this repository. The project does not authorize hidden telemetry, spyware, tracking,
or undocumented data exfiltration in the Amentys core or in hardware interfaces submitted to
the project.

This document describes the project source. It does not describe the privacy practices of
third-party websites, package registries, hosting providers, operating systems, firmware, or
applications that may be used with Amentys.

## Third-party services

Using GitHub, Rust package registries, download services, CI providers, or other external
services may result in processing under those services' own privacy policies. Review those
policies before using an external service.

## Reports and contributions

Issue reports, pull requests, and security reports may contain personal data supplied by the
sender. Do not include secrets or unnecessary personal information. Public contributions may
remain publicly available in repository history, subject to the hosting provider's policies.

## Changes

This document may be updated when the project's data practices change. A release or service
that collects data must provide its own clear privacy notice before collection begins.
